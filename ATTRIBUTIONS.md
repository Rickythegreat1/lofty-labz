# Attributions

The Lofty Labz site is built on the shoulders of these open-source projects. Each link points to the project's license.

## Frontend framework + tooling

- [React](https://github.com/facebook/react) (MIT) — UI library
- [React Router](https://github.com/remix-run/react-router) (MIT) — Routing
- [Vite](https://github.com/vitejs/vite) (MIT) — Build tool
- [TypeScript](https://github.com/microsoft/TypeScript) (Apache 2.0) — Static types

## Styling + component primitives

- [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) (MIT) — Utility-first CSS framework
- [shadcn/ui](https://github.com/shadcn-ui/ui) (MIT) — Component patterns
- [Radix UI](https://github.com/radix-ui/primitives) (MIT) — Accessible primitives (Dialog, Tabs, Tooltip, Accordion, Select, Separator, Slot, Label)
- [class-variance-authority](https://github.com/joe-bell/cva) (Apache 2.0) — Variant API
- [clsx](https://github.com/lukeed/clsx) (MIT) + [tailwind-merge](https://github.com/dcastil/tailwind-merge) (MIT) — Class name composition

## Motion + 3D + media

- [Motion](https://github.com/motiondivision/motion) (MIT) — Spring physics + variants (formerly Framer Motion)
- [Three.js](https://github.com/mrdoob/three.js) (MIT) — WebGL renderer
- [@react-three/fiber](https://github.com/pmndrs/react-three-fiber) (MIT) — React renderer for Three.js
- [@react-three/drei](https://github.com/pmndrs/drei) (MIT) — R3F helpers
- [lottie-react](https://github.com/Gamote/lottie-react) (MIT) — Lottie player for React (wraps Airbnb's [lottie-web](https://github.com/airbnb/lottie-web), MIT)

## Iconography

- [Lucide](https://github.com/lucide-icons/lucide) (ISC) — Icon set

## Testing

- [Playwright](https://github.com/microsoft/playwright) (Apache 2.0) — End-to-end + visual regression suite

## Fonts

- [DM Sans](https://fonts.google.com/specimen/DM+Sans), [Archivo Black](https://fonts.google.com/specimen/Archivo+Black), [JetBrains Mono](https://www.jetbrains.com/lp/mono/) — all licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).
